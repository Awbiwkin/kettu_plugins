# kettu-plugins

Плагины для Kettu (работают и в Bunny, Revenge, Vendetta).

| Плагин | Что делает | Ссылка для установки |
|---|---|---|
| [AI Translator](translator/) | перевод с пресетами и стилизацией, догонялка, объяснялка | `.../translator/` |
| [Seen & Log](seenlog/) | кто когда был в сети, лог удалённых и изменённых | `.../seenlog/` |
